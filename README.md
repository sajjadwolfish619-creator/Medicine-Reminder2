# Medicine Reminder (یادآور مصرف دارو)

اپلیکیشن حرفه‌ای، کامل و مدرن اندروید برای مدیریت زمان‌بندی و یادآوری مصرف داروها با طراحی اختصاصی Material 3 و زبان کاتلین و Jetpack Compose.

## 🌟 امکانات کلیدی

- **هویت بصری و طراحی مدرن:**
  - پس‌زمینهٔ گرم عاجی و کرم (`#FAF7F0`)
  - رنگ سبز مریم‌گلی و سبز تیره به عنوان رنگ اصلی (`#2D5A43`)
  - سبز نعنایی برای وضعیت‌های ثبت مصرف موفق (`#2E7D32`)
  - نارنجی ملایم برای هشدارها و نوبت‌های باقیمانده (`#D96B27`)
  - کارت‌های گرد با سایه و کنتراست استاندارد M3
- **صفحه اصلی (Home):**
  - خوشامدگویی بر اساس ساعت روز و نمایش تاریخ تقویم
  - ۴ کارت آماری: داروهای فعال، نوبت‌های امروز، مصرف‌شده و باقیمانده
  - نوار پیشرفت مصرف روزانه بر حسب درصد
  - بنر ویژه نزدیک‌ترین یادآور با دکمه اقدام سریع «ثبت مصرف»
  - فهرست کارت‌های نوبت امروز با امکان ثبت وضعیت
- **صفحه امروز (Today):**
  - جدول زمانی نوبت‌های دارویی به ترتیب ساعت
  - امکان مشاهده نوبت‌های روزهای گذشته و آینده با جابجایی تاریخ
  - دکمه‌های مستقل Taken (مصرف شد)، Missed (مصرف نشد) و Undo (بازگردانی)
- **مدیریت داروها:**
  - ثبت داروی جدید، ویرایش و حذف با گفتگوی تایید
  - تعیین شکل دارو (قرص، کپسول، شربت، قطره، آمپول، اسپری، پماد، سایر)
  - مقدار دوز تجویزشده و دستورات مصرف (مثلاً بعد از غذا)
  - تعریف چند ساعت مصرف در شبانه‌روز برای یک دارو (مانند 08:00، 14:00، 22:00)
- **فهرست جستجوی دارو (Medication Catalog):**
  - بانک اطلاعات محلی و آفلاین بیش از ۵۰ داروی پرکاربرد ژنریک و تجاری به دو زبان فارسی و انگلیسی
  - پر کردن خودکار فرم، مقدار و دستور مصرف پیشنهادی
  - امکان ثبت دستی هر نام دلخواه به صورت ۱۰۰٪ آفلاین
- **سیستم یادآور و زنگ هشدار:**
  - استفاده از `AlarmManager.setExactAndAllowWhileIdle` با هشدارهای مستقل برای هر نوبت
  - اعلانات با اولویت بالا همراه با دکمه‌های اقدام سریع (Taken / Missed) در نوار اعلان
  - پشتیبانی کامل از راه‌اندازی مجدد گوشی (`BootReceiver` و بازیابی خودکار تمامی هشدارها)
- **انتخاب و پیش‌نمایش صدای هشدار (Sound System):**
  - گزینه‌های: Gentle، Classic، Digital، Loud، Soft Bell
  - تولید واقعی شکل‌موج‌های صوتی هارمونیک و باکیفیت بدون وابستگی به فایل‌های خارجی نامعتبر
  - پیش‌نمایش صدا قبل از انتخاب و ذخیره تنظیمات
- **تاریخچه مصرف (History):**
  - نمایش ساعت برنامه‌ریزی‌شده و ساعت واقعی ثبت مصرف
  - نمودار نرخ پایبندی به برنامه مصرف (Adherence Rate)
  - فیلتر بر اساس داروی مشخص و گروه‌بندی روزانه
- **پروفایل‌های کاربری چندگانه (Multi-Profile):**
  - امکان تعریف پروفایل برای اعضای خانواده (خودم، مادر، پدر، فرزند، همسر، سایر)
  - تفکیک کامل داروها، هشدارها و تاریخچه بین پروفایل‌ها
- **پشتیبان‌گیری و بازیابی (Backup & Restore):**
  - خروجی استاندارد JSON از تمامی اطلاعات، داروها و تاریخچه
  - امکان کپی و بازیابی بدون تداخل شناسه و با بازسازی هشدارها
- **دو زبانه کامل (فارسی و انگلیسی):**
  - چیدمان استاندارد RTL در زبان فارسی و LTR در زبان انگلیسی
  - نمایش صحیح اعداد و ساعت‌ها به صورت بومی
  - حفظ نام داروهای ثبت‌شده توسط کاربر بدون تغییر ناخواسته
- **صفحه درباره برنامه (About):**
  - حاوی متن اختصاصی سجاد احمدی

## 🛠 مشخصات فنی
- **Package Name:** `com.sajjad.medr`
- **Application ID:** `com.sajjad.medr`
- **Minimum SDK:** 26 (Android 8.0 Oreo)
- **Target SDK:** 36
- **Architecture:** MVVM + Clean Repository Pattern
- **UI Toolkit:** Jetpack Compose + Material Design 3
- **Local Persistence:** Android Room Database (SQLite) + Flow
- **Asynchronous Execution:** Kotlin Coroutines & StateFlow

## 📦 نحوه ساخت و خروجی
برای ساخت فایل APK پروژه، در ریشه پروژه دستور زیر را اجرا کنید:
```bash
gradle :app:assembleDebug
```
فایل APK تولیدشده در مسیر زیر قرار می‌گیرد:
`app/build/outputs/apk/debug/app-debug.apk`

برای اجرای آزمون‌های واحد:
```bash
gradle :app:testDebugUnitTest
```
فایل فشرده کامل پروژه: `MedicineReminder_Source.zip`
